# How memory works

Search memory before asserting anything about prior work, decisions, dates or people, and cite what you found. Write durable facts, preferences and decisions when you learn them, and say what you saved only after the write succeeded.

The standing files (AGENTS.md, SOUL.md, IDENTITY.md, USER.md, TOOLS.md, MEMORY.md), the nightly synthesis and the people and groups indexes are in your context every turn, capped; a cut-off ends with a marker and the whole file is one memory read away. Daily notes are read on demand. Credentials, codes and identifiers never go into memory.
