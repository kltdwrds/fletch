# qyvr-js

Plain TypeScript primitives for running a personal agent on Cloudflare.

- `@qyvr/host`: host contracts and logic with no platform imports.
- `@qyvr/host-cloudflare`: the Cloudflare Durable Object implementation.

Apache-2.0. Contributions need a DCO sign-off (`git commit -s`).

```
pnpm install
pnpm check
```
